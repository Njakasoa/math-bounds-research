# Certified global scalar realization via Bernstein bounds

Lean 4.34.1 proof package extending the local-atlas research with one global affine-state polynomial map for 1/(1+4u²), u∈[-1,1]. It includes an executable rational Bernstein bound checker, fixed-point and switching guarantees, an explicit old-checker encoding comparison, and a formal counterexample to instantaneous moving-equilibrium tracking.

Read RESULTAT_FORMEL_FR.md for results, classical antecedents, and exact limitations. Read README_REPRODUCTION_FR.md to rebuild without network access. All methods used are classical; no novelty claim is made. The degree-five envelope optimum is not the true-range optimum.

Sources and exact rational experiments are included. Toolchains, Mathlib caches, and compiled binaries are not distributed. This is a mathematical research artifact, not a validated application model.
